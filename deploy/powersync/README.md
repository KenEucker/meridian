# PowerSync Deployment

Future location for PowerSync service configuration.

This directory is intentionally empty for `M0.1`. Sync service configuration, schemas, and sync rules are deferred to later Alpha 1 tasks.

When PowerSync projections are added, Name References must remain text-first derived artifacts. Incident note and Field Report source text syncs through the existing authorized projections; any local Name Reference index must be rebuildable from that source text, must not become a business-rule engine, and must not expose references from records the active user cannot otherwise access.
