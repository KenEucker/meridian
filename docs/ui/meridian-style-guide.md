# Brand Positioning

## Product Category

**Meridian is a Volunteer Operations Platform.**

Meridian helps organizations manage volunteers, qualifications, shifts, deployments, reports, assets, and incidents across events.

## Brand Attributes

Meridian should feel:

* Calm
* Reliable
* Professional
* Organized
* Trustworthy
* Human-centered
* Operational
* Modern

Meridian should **not** feel:

* Militaristic
* Tactical
* Emergency-only
* Corporate enterprise software
* Social media
* Gaming-inspired

The visual identity should evoke:

* Navigation
* Orientation
* Stewardship
* Coordination
* Field operations
* Situational awareness

# Logo Usage

## Primary Mark

The Meridian mark consists of:

* Circular navigation/globe motif
* Sweeping directional path
* North Star reference
* Wordmark: Meridian

## Clear Space

Maintain clear space equal to the height of the star element on all sides.

## Minimum Size

### Digital

* Icon only: 24px
* Full logo: 120px wide

### Print

* Icon only: 0.25"
* Full logo: 1.5"

# Iconography

Style:

* Outline first
* Rounded corners
* Consistent stroke width
* Minimal detail

Recommended library:

* Lucide Icons

Avoid:

* Skeuomorphic icons
* Emoji-style icons
* Filled icon sets

---

# Data Visualization

Charts should prioritize clarity over aesthetics.

Preferred:

* Bar charts
* Line charts
* Status summaries
* Staffing heat maps

Avoid:

* 3D charts
* Pie charts where possible

---

# Photography

Photography should feature:

* Real volunteers
* Operations centers
* Field teams
* Check-in stations
* Coordination activities

Avoid:

* Stock corporate meetings
* Handshake photos
* Overly staged imagery

---

# Application Personality

Every screen should communicate:

> "You know where things are. You know who is working. You know what is happening."

Meridian is not a command center.

Meridian is a coordination platform.

The visual language should emphasize situational awareness, organization, and confidence rather than urgency or crisis.
